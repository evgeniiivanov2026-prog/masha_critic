# masha_critic

«Нижегородская формула v8.0»: CLI, локальный веб и плагин Firefox/Chrome. Код и полная инструкция — в [nizhny-web/README.md](nizhny-web/README.md).

```bash
cd nizhny-web
pip install -r requirements.txt
uvicorn app:app --reload
```

Обучение в вебе доступно только администратору (`NIZHNY_ADMIN_TOKEN`). Плагин балл не считает, он спрашивает локальный сервер.

## Два фикса

**Фикс 1.** Тело статьи больше не теряется в `split()`. Раньше `analyze(text, title=заголовок)` оставлял тело пустым. Теперь в разбор входят заголовок и тело, поэтому `base_quality` видит пороги длины 200 / 700 / 1500.

**Фикс 2.** Режим `score_include_url` (поле `include_url`).

- Включён (по умолчанию в вебе и в плагине): URL статьи подмешивается в текст, домен влияет на credibility.
- Выключен: как в CLI, отдельный URL записи не участвует. Терминальный обход ленты по умолчанию работает так.

Вкладка «Сравнение» показывает численную `delta_score`.

## Ограничения

- Часть фидов по умолчанию мертва в 2026 (`feeds.reuters.com`, `apnews.com/hub` отдают 403) и попадает в блок ошибок.
- F1 на малой выборке SEED шумный. При отсутствии tp формула исходника даёт F1 `0.0`.
- Без pymorphy2/pymorphy3 метрика mislabel грубее.
- Скор — эвристика, не фактчекинг.
